# Dex-

Сборка инструмента-эксплорера для Roblox: окно навигации по игровой иерархии и свойствам объектов в духе классического Explorer/Properties из Roblox Studio, но работающее прямо в клиенте игры.

---

## 📌 Описание

Репозиторий содержит собранный (bundled) файл `out.lua` объёмом около 15 000 строк — это уже готовый к использованию билд инструмента типа **Dex Explorer**: окна с деревом всех объектов игры (`game.Workspace`, `Players`, `ReplicatedStorage` и т.д.) и панелью их свойств, позволяющего изучать структуру любой Roblox-игры «изнутри» — без доступа к исходному коду разработчика.

## ⚙️ Технологии

- **Lua** (Luau / Roblox)
- Работа с полным деревом `Instance` через рекурсивный обход `game`
- Динамическое построение UI на основе данных, а не статичной вёрстки

## 🧩 Функциональность (типовая для инструментов этого класса)

- Рекурсивное построение дерева всех объектов сцены с ленивой подгрузкой веток
- Панель свойств выбранного объекта с возможностью редактирования значений
- Поиск объектов по имени/классу
- Просмотр скриптов и их исходного текста (если доступен)

## 🏗️ Формат файла

Файл представляет собой единый скомпилированный/склеенный модуль (`out.lua`) — типичный результат сборки многофайлового Lua-проекта в один бандл для удобной раздачи через `loadstring(game:HttpGet(...))`.

## 💡 Что демонстрирует проект

- Понимание модели данных Roblox (иерархия `Instance`, рефлексия свойств)
- Опыт работы с крупными, объёмными Lua-кодовыми базами
- Знакомство с паттерном сборки/бандлинга скриптов для распространения

## ⚠️ Примечание

Такие инструменты применяются для анализа структуры сторонних Roblox-игр и часто используются вместе с эксплойтами — их использование в чужих играх без разрешения нарушает условия сервиса Roblox. Здесь файл рассматривается как артефакт инструментальной разработки (тулинг для отладки/анализа), а не инструкция к действию.
